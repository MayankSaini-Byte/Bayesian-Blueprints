Leakage Control

Efficiency is deliberately excluded because it is algebraically linked to range. Including it would let the model trivially reconstruct the target instead of learning from genuine specifications.

Domain Features

Battery-per-seat, vehicle footprint, approximate volume, and torque-per-battery ratios add engineering context that raw columns alone cannot express.

Reproducibility

The entire preprocessing and model are serialized into a single Joblib pipeline artifact. Fixed random seed, documented split, and leakage-free imputation ensure reproducible results.
